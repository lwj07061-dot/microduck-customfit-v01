# Microduck CustomFit V0.1

Personal, non-commercial 3D-printing adaptation based on Pollen Robotics' public Microduck simulation meshes. The exterior proportions are retained and scaled by 1.56× to create space for the selected FEETECH STS3215-C001 servo envelope. Approximate assembled height: 390 mm.

- [Korean print and assembly notes](README_ko.md)
- [Temporary assembly order](assembly_order_V0.1_ko.md)
- [Four-angle preview](assembly_preview.png)
- Printable meshes: `STL/` and `CUSTOM_PARTS/`
- The servo envelope gauge in `FIT_REFERENCE/` is a fit-check reference; do not print it.

This is a V0.1 fit-check model, not a mechanically validated walking robot. The original Microduck meshes are simulation/visual meshes, not a manufacturing kit. Verify servo mounting, wiring clearance, and fastener fit before printing the full set or applying power.

Source meshes: https://github.com/pollen-robotics/microduck_rl
